\# UniEase — Information Architecture



\## 1. Purpose



UniEase helps students organise academic work, manage study time,

monitor progress, and work towards academic and career goals.



This document defines the proposed pages, navigation, and main user

flows before wireframes and development.



\## 2. Research Status



This structure is an initial proposal.

Survey findings and usability testing will inform revisions.

The sections below describe planned behaviour, not completed features.



\## 3. Public Pages



| Page | Purpose |

| --- | --- |

| Welcome | Introduce UniEase and its benefits |

| Register | Create an account |

| Login | Access an existing account |

| Forgot Password | Request a password reset |



\## 4. Main Navigation



| Page | Main content and actions |

| --- | --- |

| Dashboard | Today's tasks, upcoming deadlines, study summary, and quick actions |

| Modules | Create modules and view related assignments, notes, and resources |

| Assignments | Create, edit, filter, and track assignments and deadlines |

| Calendar | View deadlines and schedule study sessions |

| Notes \& Resources | Create notes and organise study links by module |

| Focus | Start a focus timer and record study sessions |

| My Growth | View study charts, progress summaries, and milestones |

| Targets \& Dreams | Create and track academic and career goals |

| AI Study Assistant | Ask academic questions and receive study support |



\## 5. Account and Utility Navigation



| Area | Main actions |

| --- | --- |

| Notifications | View reminders and open the relevant item |

| Settings | Manage profile, theme, and reminder preferences |

| Logout | End the signed-in session |



Desktop navigation will use a sidebar.

Mobile navigation will provide access to the same destinations

through a compact menu.



\## 6. Content Relationships



\- A student manages their own modules, assignments, notes, and goals.

\- An assignment belongs to a module.

\- A note or study resource can be linked to a module.

\- A study session can optionally be linked to a module.

\- Calendar views display assignment deadlines and scheduled sessions.

\- My Growth summarises recorded study activity and milestones.

\- Goals can contain milestones and target dates.



\## 7. Main User Flows



\### Create an Assignment



Dashboard or Assignments → Add Assignment → Select Module →

Enter Title and Deadline → Save → View Assignment



\### Plan a Study Session



Calendar → Add Study Session → Select Date and Time →

Optionally Select Module → Save → View Scheduled Session



\### Complete a Focus Session



Focus → Set Duration → Start Timer → Finish Session →

Save Study Record → View Updated Progress



\### Track a Goal



Targets \& Dreams → Add Goal → Choose Academic or Career →

Add Milestones and Target Date → Save → Update Progress



\### Find a Module Resource



Modules → Select Module → Notes \& Resources → Open Resource



\## 8. Usability and Accessibility Requirements



\- Use clear and consistent page names.

\- Keep common actions easy to find.

\- Support keyboard navigation and visible focus indicators.

\- Provide labels and helpful validation messages for forms.

\- Use readable text and sufficient colour contrast.

\- Show status through text or icons as well as colour.

\- Support light and dark themes.

\- Provide clear empty, loading, success, and error states.

\- Ask for confirmation before deleting important information.



\## 9. Validation Plan



\- Review survey responses for common tasks and difficulties.

\- Ask students where they would expect to find key features.

\- Test assignment creation and study planning using wireframes.

\- Record navigation problems and revise the structure.

\- Document the reasons for significant changes.



\## 10. Next Deliverables



1\. Summarise survey findings.

2\. Revise this information architecture using the findings.

3\. Create low-fidelity wireframes for the main user flows.

4\. Test the wireframes with students.
